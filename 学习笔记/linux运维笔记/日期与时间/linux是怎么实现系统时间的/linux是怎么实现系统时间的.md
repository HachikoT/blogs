# Linux 是怎么实现系统时间的

Linux 的系统时间实现可以概括为：**用硬件时钟（RTC）在系统关机时“记住”时间，开机时用它初始化一个由内核维护的、高精度的软件时钟，这个软件时钟基于硬件计数器持续演进，并通过 NTP 等机制不断校准。**

## 硬件时钟与系统时钟

- **硬件时钟 (RTC)**：主板上的实时时钟芯片，通常由电池供电，**即使系统关机或断电也能继续计时**。它的核心作用是在系统未运行时保留时间，以便开机时“告诉”内核现在是什么时间。它也常被称为 BIOS 时钟或 CMOS 时钟。
- **系统时钟 (System Clock)**：完全由 **Linux 内核在内存中维护**的软件时钟，只在系统运行时存在。它是应用程序实际“看到”和使用的时间，以 **Unix 纪元（1970-01-01 00:00:00 UTC）以来的秒数**来表示。

## 硬件时钟怎么接入的

最直接的信息在 `/sys/class/rtc/rtcX/name` 文件中

输出通常包含驱动名和设备地址两部分：

- **rtc-rv3028 0-0052**：驱动名 `rtc-rv3028` 直接指明了芯片型号，`0-0052` 是它在I2C总线上的地址（总线0，地址0x52）。
- **rtc-m41t80 0-0068**：同理，芯片是`M41T80`，I2C地址为0x68。
- **rtc_cmos**：这是一个特例，表示RTC集成在南桥/平台中，通过传统的CMOS/LPC接口访问，并非独立的I2C/SPI芯片。
- **rtc-ti-k3 2b1f0000.rtc**：这通常是SoC内部集成的RTC，`2b1f0000.rtc` 是其内存映射地址或平台设备名。

## 维护系统时钟

内核启动初期，会调用 `hwclock --hctosys` 将硬件时钟的时间读入系统时钟。在此过程中，`hwclock` 会读取 `/etc/adjtime` 中的漂移因子，并尝试补偿硬件时钟在上次关机期间累积的误差，从而为系统时钟提供一个更准确的初始值。此后，系统时钟便由内核独立维护。

现代 Linux（2.6.21+）引入了**高精度定时器 (hrtimer)** 和动态 tick 机制，不再严格依赖固定的周期性中断。内核的 **`timekeeping` 子系统**则负责维护核心的时间状态。它持续读取高精度时钟源，计算出精确的时间增量，并维护一个**受 NTP 调整的乘数 (`mult`)**。这意味着，系统时钟的“流速”本身是微调的——当发现时钟快了或慢了，NTP 会平滑地调整这个乘数，而不是粗暴地“拨动”时间指针，从而避免时间跳跃。

在系统关闭前，通常会执行 `hwclock --systohc`，将此时已被 NTP 校准过的、相对准确的系统时钟时间写回到硬件时钟中。同时，`hwclock` 会根据本次运行期间观察到的误差，更新 `/etc/adjtime` 中的漂移因子，为下一次启动时的校正做好准备。

## 获取系统时间

如果每次调用 `clock_gettime()` 都要陷入内核，开销会很大。为此，Linux 引入了 **vDSO (Virtual Dynamic Shared Object)**。

vDSO 是内核映射到**每个用户进程地址空间**的一小段代码。当应用程序调用 `clock_gettime()` 获取 `CLOCK_REALTIME` 或 `CLOCK_MONOTONIC` 等常见时钟时，C 库（glibc）会**优先执行 vDSO 中的用户态实现**。这段代码直接读取内核暴露在共享内存中的时间数据并进行计算，**完全避免了系统调用的上下文切换开销**，使得获取时间变得极快。如果 vDSO 不可用或需要回退，才会执行真正的系统调用。

## 实时与单调

除了物理实现，Linux 还向用户空间提供了两种逻辑时间，它们基于同一套底层机制，但用途不同。

| 时钟类型              | 特性                                                              | 主要用途                                                           |
| :-------------------- | :---------------------------------------------------------------- | :----------------------------------------------------------------- |
| **`CLOCK_REALTIME`**  | **可被设置和调整**（受 NTP 或手动修改影响），可能发生“时间跳跃”。 | 记录事件发生的“墙上时间”（如日志时间戳），需要与外部世界保持一致。 |
| **`CLOCK_MONOTONIC`** | **只增不减**，从系统启动开始计时，**不受**系统时间调整的影响。    | 测量时间间隔（如计算程序耗时、实现超时），保证计时的连续性。       |
