# SSH 和 OpenSSH 的区别

SSH（Secure Shell）是一套用于在不安全网络上安全访问远程主机的协议，规定了加密通信、身份认证、会话建立、数据传输和端口转发等能力。

OpenSSH 是 SSH 协议的一套开源实现，包含客户端、服务端以及配套工具。Linux 服务器中经常说的 `ssh`，通常就是 OpenSSH 提供的命令行客户端；`sshd` 则是 OpenSSH 服务端进程。

| 名称         | 含义                           |
| ------------ | ------------------------------ |
| SSH          | 安全远程登录协议和技术体系     |
| OpenSSH      | SSH 协议的开源实现             |
| `ssh`        | OpenSSH 客户端命令             |
| `sshd`       | OpenSSH 服务端守护进程         |
| `scp`        | 基于 SSH 的文件复制工具        |
| `sftp`       | 基于 SSH 的交互式文件传输工具  |
| `ssh-keygen` | 生成和管理 SSH 密钥            |
| `ssh-agent`  | 临时管理私钥，减少重复输入口令 |

SSH 默认使用 TCP 22 端口，但服务端可以修改为其他端口。修改端口只能减少自动扫描噪声，不能代替身份认证和访问控制。

# ssh客户端和服务端的密钥保存在哪

| 用途           | 私钥在哪                                                                                    | 公钥在哪/被谁保存                                                           |
| -------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 客户端用户认证 | `~/.ssh/id_rsa`、`~/.ssh/id_ed25519`、`~/.ssh/id_ecdsa`                                     | 同目录 `*.pub`；可以手动添加到**服务端目标用户**的 `~/.ssh/authorized_keys` |
| 服务端主机身份 | `/etc/ssh/ssh_host_rsa_key`、`/etc/ssh/ssh_host_ed25519_key`、`/etc/ssh/ssh_host_ecdsa_key` | 同目录 `*.pub`；客户端首次连接后保存到 `~/.ssh/known_hosts`                 |

# 禁止 root 直接登录

推荐禁止 root 通过 SSH 直接登录，使用普通账号登录后再通过 sudo 提权：

```text
PermitRootLogin no
```

如果暂时必须允许 root 使用密钥登录，也不应允许 root 使用密码：

```text
PermitRootLogin prohibit-password
```

# 登录用户黑白名单

SSH 守护进程严格按照以下固定顺序评估这些指令，一旦某个用户或组匹配到规则，就会立即做出决定：

1. DenyUsers：检查用户是否在黑名单中。如果是，立即拒绝登录。
2. AllowUsers：检查用户是否在白名单中。如果不在，立即拒绝登录。
3. DenyGroups：检查用户所属的主组或附加组是否在黑名单中。如果是，立即拒绝登录。
4. AllowGroups：检查用户所属的主组或附加组是否在白名单中。如果不在，立即拒绝登录。
