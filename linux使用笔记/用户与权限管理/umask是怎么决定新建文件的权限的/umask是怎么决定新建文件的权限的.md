# umask 是怎么决定新建文件的权限的

`umask`（user file-creation mode mask）是进程创建文件或目录时使用的权限屏蔽掩码。它不会直接设置最终权限，而是告诉系统哪些权限位不能出现在新创建的对象上。

可以使用下面的命令查看当前 shell 的 `umask`：

```bash
rc@ubuntu:~$ umask
0002
```

## 新建文件和目录的计算基准

系统创建对象时，并不是所有类型都使用同一个初始权限（这个主要取决于用户代码实现，下面是常见模式）：

- 普通文件的基准权限是 `666`，也就是 `rw-rw-rw-`。
- 目录的基准权限是 `777`，也就是 `rwxrwxrwx`。

普通文件默认不带执行权限，这是为了避免新建的普通文件自动成为可执行文件。即使 `umask` 为 `000`，使用 `touch` 创建的普通文件通常也是 `666`，而不是 `777`。

实际权限可以理解为：

```text
普通文件实际权限 = 0666 屏蔽 umask 中的权限位
目录实际权限     = 0777 屏蔽 umask 中的权限位
```

从位运算角度看，权限位是按位屏蔽，而不是普通的十进制减法：

```text
实际权限 = 基准权限 & ~umask
```

## 查看和修改 umask

在当前 shell 中临时修改：

```bash
rc@ubuntu:~$ umask 022
rc@ubuntu:~$ 
```

该设置通常只影响当前 shell 及其后代进程。可以用 `umask -S` 查看符号形式：

```bash
rc@ubuntu:~$ umask -S
u=rwx,g=rx,o=rx
```

如果需要长期生效，应根据使用的 shell 和登录方式，将设置写入相应的 shell 启动文件，例如 `~/.bashrc` 或 `~/.bash_profile`。

系统级默认值也可能在 `/etc/profile`、`/etc/bashrc` 或其他 shell 配置文件中设置。实际生效值以创建文件时所属进程中的 `umask` 为准。
