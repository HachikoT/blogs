# 怎么查看当前用户是谁，以及属于哪些组

在 Linux 中，可以使用 `whoami`、`id` 和 `groups` 等命令查看当前登录用户，以及当前用户所属的用户组。用户组信息常用于判断用户是否具有访问文件、执行命令或使用系统设备的权限。

## 使用whoami命令查看当前用户

`whoami` 可以直接显示当前用户的用户名：

```bash
rc@ubuntu:~$ whoami
rc
```

## 使用id命令查看用户和组信息

`id` 可以一次性查看当前用户的 UID、主组和其他附属组：

```bash
rc@ubuntu:~$ id
uid=1000(rc) gid=1000(rc) groups=1000(rc),4(adm),24(cdrom),27(sudo),30(dip),46(plugdev),120(lpadmin),132(lxd),133(sambashare)
```

输出中各字段的含义如下：

- `uid=1000(rc)`：当前用户的用户 ID 是 `1000`，用户名是 `rc`。
- `gid=1000(rc)`：当前用户的主组 ID 是 `1000`，主组名称是 `rc`。
- `groups=...`：当前用户所属的全部用户组，包括主组和附属组。

也可以指定用户名查看某个用户的信息：

```bash
rc@ubuntu:~$ id root
uid=0(root) gid=0(root) groups=0(root)
```

## 使用groups命令查看所属组

`groups` 可以显示当前用户所属的用户组名称：

```bash
rc@ubuntu:~$ groups
rc adm cdrom sudo dip plugdev lpadmin lxd sambashare
```

也可以指定用户名查看其他用户所属的组：

```bash
rc@ubuntu:~$ groups root
root : root
```

如果只关心当前用户属于哪些组，使用 `groups` 比 `id` 输出更简洁；如果还需要 UID、GID 等信息，使用 `id` 更合适。
